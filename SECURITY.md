# Security Policy

## Supported versions

Only the latest release published on [WordPress.org](https://wordpress.org/plugins/zahls-ch-payment-gateway/) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately via **Security → Report a vulnerability** in this repository, or by email to support@zahls.ch. We will confirm receipt and keep you informed until a fix is released.
